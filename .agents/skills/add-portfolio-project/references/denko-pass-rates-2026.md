# 2026年度 第二種電気工事士試験の合格率

確認日：2026-11-14。公式集計表で確認できた上期の全国結果。

| 区分 | 受験者 | 合格者 | 合格率 |
| --- | ---: | ---: | ---: |
| 上期 学科 | 78,290人 | 48,692人 | 62.2% |
| 上期 技能 | 58,393人 | 42,875人 | 73.4% |

合格率＝合格者数÷受験者数×100。小数第1位に四捨五入。母数は申込者数ではない。技能には学科免除者等を含むため、両割合を掛けて総合合格率を出さない。satoの指導実績ではない。確認した公式集計表の下期・年間欄は未掲載のため推測しない。

## 図と更新方法

ポートフォリオの `index.html` 内 `#exam-results` に、0〜100%の共通尺度の横棒グラフと人数表を掲載する。学科62.2%、技能73.4%。文字でも数値を示し、色だけで区別しない。

更新時は公式情報を再確認し、年度・期・人数・割合・確認日を本資料とページで同期する。下期・年間が公表されたら上期と区別して扱う。
